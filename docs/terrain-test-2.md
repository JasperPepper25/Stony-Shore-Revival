# 0.5.0-terrain.2 — water, transitions and sandy shelves

Replace terrain.1 with the `0.5.0-terrain.2-srg.jar`; keep only one Stony Shore
Revival JAR. Restart and use a fresh test world with the current pack and settings.
Existing chunks, including areas already pregenerated by Distant Horizons, retain
the previous terrain. A same-seed fresh world is useful for comparing locations.
The version/class/Overworld/sea-level guards and WWOO exclusion are unchanged.

## Changes

- Lower basin centers more consistently below the water line, with up to three
  shallow layers of water. Some high shelves and dry rock hollows remain intentional.
- Wrap the existing per-chunk aquifer at NoiseChunk construction. In eligible
  stony-shore columns, newly carved space at Y=60..62 receives source water if the
  incoming final density is nonpositive and the global fluid picker permits water.
  Existing fluids, positive density (including structure beards), baseline-negative
  cave space, deep aquifers, other biomes and old-version blending keep their
  existing decisions. This is not a global aquifer/floodedness replacement.
- A constructor-only Mixin attaches the wrapper to the unique typed aquifer field.
  There is no overwritten factory or generation method. Attachment/sampling failure
  disables the shared terrain adapter and logs the reason. This new compatibility
  point needs pack testing; later features can still change terrain or water.
- Infer a fractional surface zero crossing, fade altitude influence to zero before
  excluding high columns, and taper the density modification smoothly through
  Y=75..87. Replace the quart-stepped stencil with continuous distance to non-shore
  biome cells. Rotate the warped noise lattice to reduce axis-aligned contours.
- Generate occasional broad low sandy shelves from a separate seeded field. The
  same field shapes the shelf and places supported sand/sandstone caps around
  Y=62..66. It does not scatter independent sand spots into every chunk. Preserves
  ores and occupied/unsupported surfaces. `generation.coastal_sandy_shelves=true`
  enables them; changing it requires a restart. The old broad V4 sand rule is used
  only when the terrain adapter is absent.
- Keep legacy pools/spires suspended while the adapter is installed. Ordinary
  texture remains; no biome or third-party feature is removed.

## Audit and comparison

Run `/stonyshore audit` **while near the suspect pool or transition**. The ZIP now
includes `observations/nearby-shore.json`: a 65-by-65-block square sampled every two
blocks, block states at Y=59..87, measured top heights, biome IDs and planned surface
estimates. It reads already loaded chunks only. It includes the command's X/Z
location, but no inventory, player identity, world seed or existing logs.

The Overworld runtime status adds aquifer-attachment and shallow-water-decision
counts. These count evaluations, not unique blocks or completed pools. Observations
include later feature/player changes; the planned surface is only an estimate.
A dry hollow above Y=62 is not automatically a failed fill. If a high transition
persists above the sampled band, include an F3 screenshot identifying its block Y.

The latest Tectonic settings are elevation boost 0.15 and erosion scale 0.25;
changing those between comparisons would also change the underlying terrain.

## Validation limits

Regression tests cover height/quart boundaries, deterministic chunk traversal,
carving bounds, water ownership/exclusions, aquifer delegation and failure behavior,
sandy-shelf coverage/coherence, and the pinned constructor/field layout. A successful
build verifies compilation/remapping, not a visual match or full-pack Mixin execution.
Raw density planning remains an estimate of Minecraft's interpolated terrain, and
later surface/river/slab features may alter the result. This is an experimental test
build, not a claim that every photographed hollow or line is fixed.
